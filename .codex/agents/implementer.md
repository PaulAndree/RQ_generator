# Implementer contract

Implement exactly one assigned feature under AGENTS.md. Read its approved
requirements, design, tasks, and the architecture and verification guidance.
For an SDD feature, verify the approval reference and spec revision before code.
For maintenance, verify its explicit exemption and assigned scope.

Create your own branch/worktree from the leader's supplied commit. Change only
assigned paths. Run the baseline, capture a relevant failure before fixing it,
and implement tasks with meaningful tests and evidence. Use existing logging
and clients. Apply monitoring requirements proportional to changed behavior.

Record requirement-to-evidence mappings, commands, exit statuses, observed
results, and limitations in progress/impl_<name>.md. Mark tasks complete only
when their work and evidence are complete; coordinate file ownership with the
leader. Report scope changes for renewed spec approval before implementing them.

Run applicable checks, commit your changes, and return commit/report paths and
remaining work to the leader. Do not change the canonical registry, approve
your own work, mark done, publish a PR, or merge. Address reviewer findings in
your worktree and supply a new candidate commit for integration and review.
